# QQ 邮箱通道

这是规划中的常开任务网关的轻量替代：不租服务器，不保持进程在线。两台已经登录各自 QQ 邮箱的设备，用邮件互相留下一条短文本。混合工作区的文件同步仍然在本机完成，不经过邮箱。

## 它做什么

- 发送一封纯文本邮件。主题固定为 `PortableAI note|task|result: 标题`。
- 只连接 QQ 官方端点：`smtp.qq.com:465`（SSL）和 `imap.qq.com:993`（SSL），并校验服务器证书。没有“自定义服务器”选项，授权码不会被发到其他主机。
- 收取时只读搜索主题含 `PortableAI` 的邮件，使用 `BODY.PEEK`，不删除、不改已读标记。
- 界面把收件显示出来。要继续处理，必须由你确认后填入任务框，再自己点击发送任务。

## 它不做什么

- 不同步文件、目录或记忆库，不接收附件。正文上限 24000 字，单封原始邮件超过 64KB 会跳过。
- 不保存授权码、正文或标题到 U 盘。操作审计只记收件人数、类型和字节数。
- 不把收到的正文交给模型，也不把它当成待执行命令。邮箱内容可以是任何人写来的文字。
- 不加密。QQ 能看到明文。不要写 API Key、授权码、密码或私人文件。

## 使用前

1. 打开 QQ 邮箱 → 设置 → 账户，开启 IMAP/SMTP 服务。
2. 生成授权码。那是 16 位字符，不是 QQ 登录密码。
3. 在程序里点“QQ邮箱”，填写自己的 `@qq.com`、`@foxmail.com` 或 `@vip.qq.com` 地址、授权码和对方邮箱。

关闭程序后授权码即消失。真实收发需要该邮箱已开启服务并且本机能够访问 QQ；离线测试不连接 QQ。
